# AudioLayerEngine

Professional stand-alone layered music generation engine.
Designed for dynamic audio composition using MIDI and synthesizer layers.

## Features
- Layer-based composition
- MIDI export and metadata generation
- Real-time pause/resume support
- Music theory-aware pattern generation
- High-performance orchestrator

## Installation
```bash
pip install -e .
```

## Usage
```bash
python -m audiolayer --config configs/example.json --compose
```
